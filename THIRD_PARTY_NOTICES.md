# Brand assets

## Microsoft WebView2

The native Windows host uses Microsoft.Web.WebView2 SDK 1.0.4258.31. The portable distribution includes the SDK's original license and notices as `licenses/WebView2-LICENSE.txt` and `licenses/WebView2-NOTICE.txt`. The Microsoft Edge WebView2 Runtime is installed separately and is not redistributed in this package. Package source: https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4258.31.

Provider marks are vendored from @lobehub/icons-static-svg 1.95.1, https://github.com/lobehub/lobe-icons. Only the monochrome currentColor fill is set to the interface foreground; path geometry is unchanged. Assets are bundled locally with no runtime CDN request. Brand names and marks identify the respective services.
