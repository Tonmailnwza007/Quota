# Quota

AI subscription limits, right in your Windows system tray.

**[Download for Windows x64](https://github.com/Tonmailnwza007/Quota/releases/latest)**

- Track two separate Codex accounts: App and CLI.
- Check Antigravity usage without keeping its app or CLI open.
- Optionally show Claude and GitHub Copilot.
- Choose visible providers, fold account cards, and set low-quota alerts.
- Start with Windows when you want it.

## Get started

Extract the entire ZIP and run **quota.exe**. Click its tray icon to open the panel. Settings contains provider switches, alert thresholds, and the startup option.

Windows x64 and Microsoft Edge WebView2 Runtime are required. .NET is included. The portable app is unsigned.

No personal accounts, credentials, settings, or usage history are included. Quota uses existing sign-ins on your computer; demo identities are synthetic.
